# diorama

A roguelite tower defense prototype in Rust and [Bevy](https://bevyengine.org/) 0.19. Hold a human outpost against an alien horde: shape its path with walls and towers, then watch thousands of enemies pour into the kill zones you built. Each wave has an untimed build phase with full undo, then a wave phase where you fire abilities. After every wave you claim a new chunk of map, which may bring a new nest. Your score is the number of waves you survive.

Work in progress, and the name is a code name.

## Running

```sh
cargo run --release
```
